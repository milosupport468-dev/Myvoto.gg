# MYVOTO.GG

Estructura inicial con Next.js, TypeScript y Supabase.

## Instalar
```bash
npm install
cp .env.example .env.local
npm run dev
```

Completa las variables de Supabase en `.env.local`. No publiques claves secretas. Esta es una base inicial: autenticación, base de datos, votos, insignias y pagos aún deben implementarse. Solo incluye la tienda legal.
